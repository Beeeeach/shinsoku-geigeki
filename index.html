01ABOUT

神速の迎撃戦線とは？

文化祭史上、最も速い戦場へ。

「神速の迎撃戦線」は、 台車に乗りながらターゲットを狙う シューティングアトラクションです。

スピード、判断力、そして正確なエイム。
すべてを駆使して、 ハイスコアを目指せ。

02GAME SYSTEM

ルールはシンプル。しかし、攻略は簡単ではない。

SYSTEM 01

RIDE

台車に乗り、コースを進む。 動きながら戦うことで、 狙いを定める難しさが増していく。

SYSTEM 02

AIM

次々と現れるターゲットを 素早く発見し、 正確に狙え。

SYSTEM 03

SCORE

多くのターゲットを撃ち抜き、 最高得点を目指せ。 あなたは戦場を制覇できるか。
